# KAELIS About Package — Import Instructions

Copy the `Assets/_Project/Kaleidoscope2/About/` folder from this archive into the root of the Unity project.

Suggested destination:

```text
C:\Projects\CLIPS\Kaleidoskop2\Assets\_Project\Kaleidoscope2\About
```

- provide text and metadata for the KAELIS “About / О программе” screen;
- document author, copyright, music credits, artist pseudonym, and contact information;
- provide Codex-ready implementation instructions;
